# Not Enough Potions
[**Play Me**](https://schwermc.github.io/Not_Enough_Potions/) <br />

## Controls
WASD for Movement <br />
Mouse to look around <br />
I for player inventory <br />
P for pause menu <br />
E at the potion station  <br />
